Frequently Asked Questions

Are payments live?

No. This preview does not accept or verify payments. A secure payment backend must be configured first.

Can I track orders?

The order-history interface is included; live tracking requires a connected provider API and backend.

Can users create Child Panels?

The Child Panels section is included. Access rules and provisioning need admin configuration.
